VideoFlowPlayer 개인정보처리방침

시행일: 2026년 10월 15일

VideoFlowPlayer는 이용자의 개인정보를 수집하지 않으며, 어떤 정보도 외부로 전송하지 않습니다.

1. 수집하는 개인정보

VideoFlowPlayer(이하 "앱")는 이용자의 개인정보를 수집하지 않으며, 외부로 전송하지도 않습니다.

  • 회원가입, 로그인, 이름·이메일·전화번호 입력을 요구하지 않습니다.
  • 앱에는 인터넷 접근 권한이 없어, 앱이 처리하는 어떤 정보도 개발자나 외부 서버로 보내지지 않습니다.
  • 이용자가 재생하는 동영상, 자막, 캡처 이미지의 내용은 개발자가 볼 수 없습니다.

2. 이용자의 기기 안에만 저장되는 정보

앱 기능을 위해 아래 정보가 이용자의 기기 안에만 저장됩니다. 이 정보는 기기 밖으로 나가지 않습니다.

항목저장 위치목적
자막 표시 설정 (켜기/끄기, 글자 크기, 배경, 위치)앱 전용 저장공간다음 실행 때 같은 설정 유지
즐겨찾기 폴더 이름과 위치앱 전용 저장공간원클릭 파일 이동
설명서 확인 여부앱 전용 저장공간첫 실행 때만 설명서 자동 표시
변환된 자막 파일앱 캐시한글 자막(EUC-KR, SMI) 재생
화면 캡처 이미지 (PNG)사진 › VideoFlowPlayer 앨범이용자가 요청한 캡처 저장
캡처 묶음 (ZIP)다운로드 › VideoFlowPlayer 폴더이용자가 요청한 일괄 저장

재생목록은 앱 실행 중에만 메모리에 있고, 앱을 끄면 사라집니다.

3. 접근 권한

앱은 위치, 연락처, 카메라, 마이크 등 민감한 권한을 요청하지 않습니다. 파일에는 이용자가 직접 고른 범위에서만 접근합니다.

접근 대상언제범위
동영상·자막 파일이용자가 파일 추가나 자막 파일 불러오기로 고를 때고른 파일만
폴더이용자가 폴더 추가, 이동, 즐겨찾기 추가로 고르고 허용할 때고른 폴더 안의 파일만
사진·다운로드 폴더이용자가 캡처하거나 ZIP으로 저장할 때앱이 만든 파일만 저장

이용자는 휴대폰의 설정 › 앱 › VideoFlowPlayer에서 언제든 저장공간 접근을 정리하거나 앱 데이터를 지울 수 있습니다.

4. 제3자 제공과 처리 위탁

앱은 개인정보를 수집하지 않으므로 제3자에게 제공하거나 처리를 위탁하지 않습니다.

  • 광고 SDK, 사용 통계·분석 도구, 오류 보고 도구를 넣지 않았습니다.
  • 앱이 쓰는 동영상 재생 라이브러리(Google AndroidX Media3)는 기기 안에서만 동작하며 정보를 전송하지 않습니다.
  • 이용자가 공유 버튼으로 캡처 이미지를 다른 앱에 보내면, 그 이후의 처리는 받는 앱의 개인정보처리방침을 따릅니다.

5. 보관 기간과 삭제

기기 안의 정보는 이용자가 지울 때까지 기기에만 남고, 아래 방법으로 언제든 지울 수 있습니다.

  • 설정·즐겨찾기·자막 캐시: 즐겨찾기는 이동 탭의 휴지통 아이콘으로 지웁니다. 전부 지우려면 설정 › 앱 › VideoFlowPlayer › 저장공간 › 데이터 삭제를 누르거나 앱을 삭제합니다.
  • 캡처 이미지: 캡처 탭의 휴지통 아이콘이나 갤러리 앱에서 지웁니다.
  • ZIP 파일: 파일 관리자의 다운로드 › VideoFlowPlayer 폴더에서 지웁니다.

앱을 삭제해도 사진·다운로드 폴더에 저장한 캡처와 ZIP은 이용자의 파일로 남습니다.

6. 이용자의 권리와 아동의 개인정보

개발자가 보관하는 이용자 정보가 없으므로, 열람·정정·삭제를 요청할 대상 정보도 없습니다. 기기 안의 정보는 5항의 방법으로 이용자가 직접 확인하고 지울 수 있습니다. 궁금한 점은 7항의 연락처로 문의하시면 답변드립니다.

앱은 만 14세 미만 아동을 포함한 누구의 개인정보도 수집하지 않습니다.

7. 방침 변경과 문의
